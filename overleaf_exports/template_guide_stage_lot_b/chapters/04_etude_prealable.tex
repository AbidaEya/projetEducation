\chapter{Etude préalable}

\section{Description de l'existant}
Interfaces hétérogènes et absence de parcours unifiés par rôle; faible ergonomie pour le suivi académique quotidien.

\section{Critiques de l'existant}
Navigation peu fluide, visibilité limitée sur les états (soumissions, absences, demandes), et manque d'harmonisation visuelle.

\section{Solutions proposées}
Conception d'une SPA React/TypeScript avec routing structuré, composants réutilisables, pages par rôle et appels API centralisés.

\section{Développement de la solution finale}
Lot B implémente les interfaces fonctionnelles, l'expérience utilisateur, les formulaires métier et la communication frontend-backend.
