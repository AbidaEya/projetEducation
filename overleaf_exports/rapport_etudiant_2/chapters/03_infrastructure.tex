\chapter{Infrastructure informatique}

\section{Matériel informatique}
Le développement frontend a été réalisé sur un poste de travail standard avec navigateurs de test, accès réseau pour l'intégration continue et tests fonctionnels.

L'environnement matériel permet l'exécution simultanée du frontend (Vite) et du backend (Spring Boot) pour valider les scénarios de bout en bout.

\section{Logiciels utilisés}
\begin{itemize}
  \item \textbf{Node.js} et \textbf{npm} ;
  \item \textbf{React}, \textbf{TypeScript}, \textbf{Vite} ;
  \item bibliothèques UI/CSS : TailwindCSS, composants réutilisables ;
  \item \textbf{React Router} pour la navigation ;
  \item \textbf{VS Code}, \textbf{Git/GitHub}, navigateur web ;
  \item Postman pour vérifier les réponses API pendant l'intégration.
\end{itemize}
