\chapter{Présentation du thème du stage}

\section{Champ de l'étude et objet du stage}
Le thème du stage porte sur la réalisation d'une \textbf{plateforme éducative web} permettant de gérer les utilisateurs, les cours, les absences, les demandes administratives, les réclamations et les notifications.

L'objet de mon lot consiste à :
\begin{itemize}
	\item concevoir le modèle de données ;
	\item implémenter les services métiers ;
	\item exposer les fonctionnalités via des endpoints REST ;
	\item garantir la cohérence des traitements administratifs côté serveur.
\end{itemize}
