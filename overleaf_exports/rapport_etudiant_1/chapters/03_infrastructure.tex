\chapter{Infrastructure informatique}

\section{Matériel informatique}
Le développement a été réalisé sur un poste de travail standard (ordinateur portable), avec accès réseau local et internet pour le versionnement, la récupération des dépendances et les tests d'intégration.

Le matériel utilisé est suffisant pour :
\begin{itemize}
  \item exécuter le backend Spring Boot ;
  \item lancer la base de données de développement ;
  \item tester les endpoints via Postman et navigateur.
\end{itemize}

\section{Logiciels utilisés}
\begin{itemize}
  \item \textbf{Java 17+}, \textbf{Spring Boot 3.x}, \textbf{Maven} ;
  \item \textbf{Hibernate/JPA} pour la persistance ;
  \item \textbf{MySQL} (profil principal) et \textbf{H2} (profil développement/test) ;
  \item \textbf{Postman} pour les tests des API REST ;
  \item \textbf{Git/GitHub} pour le suivi des versions ;
  \item \textbf{VS Code} comme environnement de développement.
\end{itemize}
