# Postman setup (Education Backend)

## 1) Démarrer l’API
Base URL:
- `http://localhost:8081/api`

Health check rapide:
- GET `http://localhost:8081/api/health`

## 2) Importer la collection Postman
Importe la collection existante:
- `Education_Platform_API.postman_collection.json`

(Optionnel) Tu peux remplacer dans Postman `http://localhost:8081` par ton URL si tu changes le port.
